- **Aesthetic**: Warm off-white / light grey palette (`#F4F4F0`), bold black editorial typography (`#0A0A0A`), oversized headings, and configurable dynamic accent colors.
- **Cinematic Hero**: Multi-layer breathing ambient background video + 3-stage scroll-driven portrait transformation + dynamic SVG signature draw reveal.
- **Data-Driven Showcases**:
  - **PRI0RA**: AI-powered email intelligence flagship project.
  - **Academic Credibility**: Published research in *Indian Journal of Computer Science and Technology (INDJCST), 2026* on Java Security Architecture.
  - **Career Timeline**: Roles at AIRC (Internship), RiseInRise (Freelance), and Woxsen Student Council (E-Cell Senior Exec / Tech Head).
  - **Kinetic Stack**: Interactive scroll-responsive typography categorized across languages, frontend, backend, databases, AI/ML, cloud, and dev tools.
  - **Human Story**: Beyond code storytelling (Swimming, Beaches, Music).
- **Performance & A11y**: Hardware-accelerated transforms, full `prefers-reduced-motion` compliance, responsive image optimization, and semantic WCAG AA structure.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion & Scroll**: [Motion](https://motion.dev/) & [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript 5](https://www.typescriptlang.org/)

## 🚀 Getting Started

### Prerequisites
- Node.js 20.x or higher
- npm 10.x or higher

### Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Build & Production
```bash
npm run build
npm run start
```
